# 17-容器与 DevOps · 目录

本章建立从开发环境到生产运行的容器化共同语言。重点不是背命令，而是解释镜像如何构建、容器如何隔离、数据与网络如何流动，以及故障怎样定位和恢复。

| 文件                                     | 核心内容                                                  |
| ---------------------------------------- | --------------------------------------------------------- |
| [Docker 高频面试题](Docker高频面试题.md) | 容器原理、Dockerfile、存储、网络、Compose、安全与生产排障 |

## 推荐顺序

1. 先区分镜像、容器、仓库与虚拟机，理解隔离和资源限制来自哪里。
2. 再掌握 Dockerfile 分层、构建缓存、多阶段构建与启动命令。
3. 接着理解 volume、bind mount、容器网络和端口发布。
4. 最后用 Compose、健康检查、日志、资源限制和安全基线串起生产运行。

## 回答框架

1. **对象**：现在讨论的是镜像构建、容器运行、主机还是编排层？
2. **边界**：数据、网络、权限和资源的边界在哪里？
3. **故障**：进程退出、不可用、OOM、磁盘满或网络不通分别怎样观察？
4. **验证**：用哪些命令、指标和恢复演练证明配置有效？
