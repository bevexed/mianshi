## 必须练到脱口而出的四题

这四题的共同特点是：**心里有真实的负面情绪，
但嘴上必须给出一个客观、不抱怨、指向未来的版本。**
不练到脱口而出，现场很容易带出情绪或者说漏。

1. **跳槽频率** —— 2020-2022 三年三家 → 用「趋势」化解「频率」
2. **欧塬只做了两个月** —— 用「合同签约主体不一致」这个原则性理由
3. **为什么想离开新中大** —— ⚠️ 你的真实评价（pua/加班/技术老旧）
   一个字都不能直说，见文件里的转译表
4. **是不是要转后端** —— 「前端的边界不止到浏览器」+「这些都是前端基建」

## 带团队之后新增的六题

简历已改为「前端负责人，带 4 人团队」，
**这个 title 会让管理题占到 20-30%**：

Q7 怎么带 · Q8 怎么分任务 · Q9 code review 怎么做 ·
Q10 有人不认同选型 · Q11 还写不写代码 · Q12 能接受不带人吗

**⚠️ Q12 尤其重要**——你投的深圳 25-35K 区间
很多是资深个人贡献者岗位，**两套说法都要准备**，看 JD 决定用哪套。

## 🔒 安全提醒（重要）

`/Users/b/web/jianli` 是 git 仓库，remote 指向
`github.com/bevexed/jianli`。**目前是私有的**（未登录访问返回 404），
但被追踪的文件里包含：

```
燊芒/vpn/ddll.ovpn          ← 前雇主 VPN 配置
燊芒/vpn/ta.key             ← TLS 密钥
燊芒/vpn/账号密码.adoc       ← 凭证
燊芒/账号.md
公司评价.md                 ← 对现东家的负面评价
```

**这些在 git 历史里**。一旦仓库误设为 public，
或者你把它分享给任何人，就是实打实的事故——
而且是**前雇主的凭证**，性质比自己的密码更麻烦。

**建议**：确认凭证是否还有效；无效的至少从工作区删掉并加 `.gitignore`；
还有效的话历史记录也要清（`git filter-repo` 或重建仓库）。
