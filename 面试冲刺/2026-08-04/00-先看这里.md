# 先看这里：明天下午 4 点面试

这不是一套需要全部背完的题库。它只负责三件事：

1. 让你开场不乱，能用一句话说清自己的定位。
2. 让你把真实项目讲完整，经得住连续追问。
3. 让你遇到短板时不硬编，能平稳转回自己的优势区。

## 明天的目标

面试官结束时应形成这个判断：

> 这是一个前端交付能力成熟、实际承担过 Node.js 后端和部署链路、正在向前端偏全栈发展的人；不是只看过 NestJS 教程，也不会把不熟的技术包装成生产经验。

## 面试结束后

- [2026-08-04 面试复盘](10-本次面试复盘.md)：记录实际问题、履历稳定性风险和下次 40～60 秒答案。

## 优先级

### P0：必须开口练

- 60 秒自我介绍。
- NestJS 采集服务的 2 分钟版本。
- 为什么用队列、怎么幂等、失败怎么恢复。
- 为什么从前端扩展到全栈。
- MongoDB、Java、Koa 没有深度生产经验时怎么回答。
- 一道 AI 助手系统设计题。

### P1：有余力再补

- Vue 3 响应式、Composition API 和组件性能。
- MySQL 索引与事务、Redis 缓存与锁。
- Web 安全和 C 端性能优化。
- Next.js 项目或复杂前端项目的第二轮追问。

### 明天主动跳过

- Java 底层、Spring 源码和复杂领域设计。
- Koa 源码、MongoDB 分片实现细节。
- 从头刷完整算法题库。
- 把所有已有知识库文章重新读一遍。

## 使用规则

1. 每道题先关掉答案口述，控制在 30–90 秒。
2. 回答顺序固定为“结论 → 项目证据 → 边界或取舍”。
3. 看到 `【需本人确认】`，必须按真实代码或记忆确认；确认不了就删掉那句话，不补故事。
4. 不会时用 [短板回答模板](06-短板与高压问题.md#通用不会题模板)，不要只说“不知道”。
5. 超时就减少阅读深度，不挤睡眠，也不占用面试前的状态恢复时间。

## 最后一条

你明天不需要证明自己无所不知，只需要稳定证明三件事：前端能力成熟、Node.js 项目真实、面对边界诚实且有解决问题的方法。
