# 反问与检查清单

## 反问技术面试官

优先问 2 ～ 3 个，选择与当轮讨论最相关的问题，不要一次全部念完。

1. 这个岗位当前更需要补强的是前端架构、Node BFF，还是实时行情与交易场景？
2. Node.js 在团队里主要承担 SSR、BFF、网关编排，还是也承载核心业务服务？
3. 行情图表目前主要使用成熟图表方案，还是有自研 Canvas/WebGL 渲染层？选型最关注什么？
4. 实时链路的规模和核心指标是什么，例如订阅量、端到端延迟、断线恢复和错误率？
5. Next.js/Nuxt.js 的落地范围多大？服务端渲染的缓存、灰度和可观测性由谁负责？
6. 前端组件体系和多端复用目前最大的痛点是什么？
7. 团队如何做金融业务的安全评审、变更审批、灰度和事故复盘？
8. 如果我加入，前三个月最希望我交付什么结果？

## 反问主管

1. 这个岗位的职级定位、汇报关系和团队分工是怎样的？
2. 团队目前最重要的一项技术或业务目标是什么？最大的阻力在哪里？
3. 对这个岗位做得“合格”和做得“优秀”，半年后的判断标准分别是什么？
4. 业务覆盖多个市场后，团队如何协调交易时段、版本发布和线上值守？
5. 团队在工程效率与金融稳定性之间通常如何做决策？

## 反问 HR

1. 本岗位的职级、薪资结构、奖金和调薪周期如何构成？
2. 试用期长度、薪资比例及转正标准是什么？
3. 团队日常工作时间、发布窗口和线上值守安排如何？
4. 后续面试轮次、每轮重点和预计反馈时间是什么？

周一之前可以具体确认：“这个岗位总共几轮、周一这轮的面试官角色是什么、是否包含现场编码？”现有公开材料不足以确定本岗位固定三面。

## 薪资沟通方法

先确认薪酬口径：固定部分、浮动奖金、发薪次数、试用期比例、福利和考核条件。岗位公开薪酬范围可以作为预算背景，不等于候选人的真实工资。

> 我会综合考虑岗位职责和整体薪酬。我的期望范围是【期望范围】，也希望了解固定与浮动部分、奖金条件以及对应的职级。

被问现薪时，先澄清固定、浮动和年度口径，再按本人意愿私下沟通。公开仓库不填写真实金额、薪资流水、私人底线或个人报价。

## 面试前一天

- [ ] 60 秒自我介绍脱稿说两遍，总时长控制在 50 ～ 80 秒。
- [ ] 两条项目主线各说一遍，明确“我负责”与“团队结果”。
- [ ] 完成一次 A 轮模拟，并把最卡的 3 题写进练习记录。
- [ ] 手写更新调度器与 `nextTick`、Koa compose 和并发请求池，核对 05 的验收点。
- [ ] 画一遍实时行情链路，重点说明快照与订阅之间如何消除漏数窗口。
- [ ] 复习 Node 事件循环、SSR/BFF、Redis 幂等、Web 安全。
- [ ] 准备简历、岗位截图、纸笔、电脑、电源和耳机。
- [ ] 检查面试时间、地点或会议链接、联系人与通勤时间。
- [ ] 保证项目演示不暴露客户数据、密钥、内部地址和账号。

## 面试前 60 分钟

- [ ] 不再扩展新知识，只看[先看这里](00-先看这里.md)和自己的 3 个卡点。
- [ ] 关闭消息通知，检查摄像头、麦克风、网络和屏幕共享范围。
- [ ] 打开简历、JD 和一张空白纸；线上面试不要打开大段标准答案。
- [ ] 喝水、活动，预留 10 分钟进入状态。

## 面试中

- [ ] 先确认题目和约束，再给结论。
- [ ] 技术题至少说明一个取舍或失败条件。
- [ ] 项目题说明个人动作，不把团队成果全部归到自己名下。
- [ ] 不会时给出已知边界和排查路径，不编造实践。
- [ ] 系统设计先讲主链路，再补异常、安全和可观测性。
- [ ] 面试官纠正后先复述理解，再调整答案，不争抢话语。

## 结束表达

> 今天交流后，我对这个岗位的实时行情、前端架构和 Node.js 服务侧职责更清楚了，也觉得和我过去做复杂前端、服务端编排及工程治理的经历比较匹配。感谢您的时间，我也很期待后续有机会继续交流。

## 面试结束后 15 分钟

- [ ] 立即记录所有能回忆出的题目，不先查答案。
- [ ] 标记“答得好、答得浅、答错、不会”四类。
- [ ] 对答错与不会的问题各写一句正确结论和一个可验证来源。
- [ ] 记录岗位新增信息：团队、职责、技术栈、流程、工作安排和风险点。
- [ ] 如果进入下一轮，只补暴露出的前三个缺口。
