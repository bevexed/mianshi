# 2026-08-04 面试冲刺包设计

## 目标

在当前知识库根目录生成一个可随时删除的临时目录，帮助候选人在 2026 年 8 月 4 日下午 4 点面试前，用四小时以上的准备时间完成定向复习和开口训练。

这套材料服务于一个以前端为主、向 Node.js 全栈扩展的岗位。重点覆盖 Vue、TypeScript、NestJS、MySQL、Redis、MongoDB 选型、AI API 接入和常规 Web 安全，不扩展到与岗位关系较弱的 Java 深层原理。

## 输出位置与结构

输出目录为仓库根目录下的 `临时-2026-08-04-面试冲刺/`。它与通用知识库分离，不修改现有专题文章，面试结束后可以整体删除。

目录包含以下 Markdown 文件：

1. `00-先看这里.md`：使用方法、优先级和四小时复习时间表。
2. `01-岗位画像与应对策略.md`：匹配项、风险项和面试主线。
3. `02-自我介绍.md`：60 秒版、30 秒版和表达提醒。
4. `03-NestJS采集项目主线.md`：项目叙述、技术决策和连续追问。
5. `04-前端项目备选故事.md`：选择两个可支撑 Vue、工程化或复杂前端能力的项目故事。
6. `05-核心技术速答.md`：Vue、TypeScript、NestJS、数据库、AI 和安全的短回答。
7. `06-短板与高压问题.md`：MongoDB、Java、Express/Koa、全栈定位和年限问题。
8. `07-模拟面试.md`：一套按真实面试顺序组织的问题、追问和参考要点。
9. `08-反问薪资与检查清单.md`：反问、薪资口径、设备和面试前状态检查。
10. `09-知识库最短索引.md`：只链接当前仓库中最相关的已有文章。
11. `练习记录.md`：记录卡顿问题、需补答案和最后一次复述结果。

## 内容原则

- 先给可口述的短答案，再给追问展开，不把材料写成长篇教程。
- 项目表达遵循“背景与目标、约束、个人行动、结果、复盘”的顺序。
- 不编造业务规模、性能数据或职责；无法由现有材料确认的个人事实标为 `【需本人确认】`。
- Java 只准备能力边界和转回 NestJS 主线的话术，不主动引导面试官深挖 Java。
- MongoDB 重点准备与 MySQL 的选型边界，不伪装生产经验。
- AI 重点覆盖 SSE、停止生成、上下文裁剪、超时重试、成本、安全与降级。
- 所有复习链接必须指向仓库内真实存在的文件。

## 四小时训练节奏

1. 40 分钟：岗位画像、自我介绍和面试主线。
2. 70 分钟：NestJS 采集项目与前端备选项目，必须开口复述。
3. 70 分钟：核心技术速答，只处理岗位高频主题。
4. 50 分钟：按顺序完成一次模拟面试并记录卡顿点。
5. 30 分钟：只修补卡顿答案、检查设备和整理状态。

下午 3 点后停止扩展新知识，只看自我介绍、项目主线、短板话术和检查清单。

## 验证方式

- 检查输出目录及 11 个文件全部存在。
- 检查所有仓库内相对链接均可解析到真实文件。
- 扫描空标题、占位文本和未闭合代码围栏。
- 检查自我介绍、项目主线、短板话术和模拟面试之间没有事实冲突。
- 检查临时目录之外没有产生非设计范围内的修改。
