# MongoDB 高频面试题补充方案

## 目标

在 `15-数据库` 中新增一篇可用于中高级前端、Node.js 和全栈岗位复习的 MongoDB 高频面试题。内容需要覆盖核心原理、工程取舍和常见追问，并与现有 MySQL、Redis 文档保持相近的技术深度与表达风格。

## 内容范围

新增 `15-数据库/MongoDB高频面试题.md`，按“问题 → 核心回答 → 追问或常见误区”组织，覆盖：

- MongoDB 的文档模型，以及与关系型数据库的主要差异；
- 适用场景、不适用场景与选型边界；
- BSON、集合、文档、`ObjectId` 与 16 MiB 文档大小限制；
- 嵌入和引用的数据建模取舍；
- 单字段、复合、多键、唯一、稀疏、部分、TTL 和文本索引；
- 复合索引字段顺序、覆盖查询、排序、选择性和 `explain()`；
- Aggregation Pipeline 的常用阶段及优化原则；
- 单文档原子性、多文档事务、读关注和写关注；
- 副本集的高可用机制，以及故障切换期间的边界；
- 分片、分片键选择、热点与数据倾斜；
- 深分页、慢查询、大文档、无界数组和连接治理等常见问题。

不展开 MongoDB 安装命令、Atlas 控制台操作、特定 ODM 的完整教程或运维手册；这些内容超出高频面试复习的主线。

## 表达与示例

- 回答先给结论，再说明机制、适用条件和代价，避免只背定义。
- 对版本或部署方式敏感的行为明确边界，不使用“MongoDB 没有事务”“副本集绝不丢数据”等绝对表述。
- 示例使用 MongoDB Shell 风格的 JavaScript，保持简短并注明索引字段顺序的原因。
- 将 MySQL 对比用于解释取舍，不把两类数据库简单描述为互相替代。
- 文末提供一组简短的面试回答模板和自测清单，帮助快速复习。
