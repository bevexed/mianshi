## 面试答题模板

按追问深度准备三档答案：

- **10 秒**：一句话说清定义或根因，再给首选防线。
- **30～60 秒**：补齐成立条件、根因防护、纵深防御、方案边界和验证方式。
- **90 秒场景题**：影响与止损 → 证据保全 → 分层假设 → 验证 → 根因修复与回归 → 监控和复盘。

遇到漏洞题，按同一主干组织 30～60 秒答案：

1. **一句话定义**：它是什么，破坏了哪条信任边界？
2. **成立条件**：攻击者能控制什么，浏览器或服务端还提供了什么能力？
3. **根因防护**：先说参数化、输出编码、对象授权、目标允许列表等直接控制。
4. **纵深防御**：再说 CSP、SameSite、网络隔离、最小权限、限流、WAF 和告警。
5. **方案边界**：明确 HttpOnly、CORS、HTTPS、JWT 等不能解决什么。
6. **验证方式**：给一个负向用例、自动化门禁、运行时信号或项目场景。

面试官继续追问时，再展开 `source → transform → sink`、浏览器/服务端职责、失败策略和工程取舍。

## 复习优先级

### 15 分钟突击

先记住五个必须脱口而出的结论：

1. XSS 的根因是不可信数据进入可执行上下文，首选按上下文安全输出，而不是关键词过滤。
2. CSRF 依赖浏览器自动携带身份凭据和缺失的请求意图校验，CORS 不是它的通用防线。
3. 各类注入的共同根因是数据改变了解释器结构，首选结构与数据分离。
4. 认证回答“你是谁”，授权回答“你能否对这个资源做这个动作”，前端守卫不能代替服务端授权。
5. 参数化、输出编码、对象授权、目标允许列表等是根因控制；CSP、WAF、限流和告警通常是纵深防御。

剩余时间优先口述 XSS、CSRF、CORS、token 存储、Session/JWT、SQL 注入、SSRF、文件上传、HTTPS/CSP。每题至少能讲“结论 + 两层防护 + 一个边界”。

### 1 小时复习

完整过一遍 [高频面试题](Web安全高频面试题.md)，重点回答其中的粗体结论、常见追问和最后 3 道场景题。答不出来再跳转专题，不顺序通读所有细节。

### 二轮与中高级面试

补对象/租户授权、OAuth/OIDC、原型污染、SSRF 的 DNS/重定向边界、安全头、供应链、权限回归和事件响应，并准备一个自己项目中的真实安全取舍。
