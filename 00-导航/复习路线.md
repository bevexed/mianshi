# 复习路线

路线按可用时间和基础差异裁剪。优先修复“理解错误”，再增加新知识；只背结论但说不出边界，不算掌握。

## 一个月路线

### 第 1 周：语言、浏览器与算法

- JavaScript：类型、作用域、this、原型、Promise、事件循环。
- TypeScript：联合/条件/映射类型、常用工具类型和工程配置。
- 浏览器与网络：缓存、跨域、认证、XSS/CSRF、渲染流程。
- 算法：每天 2 ～ 3 题，覆盖链表、栈队列、树、二分和排序。

每道算法题记录：输入边界、思路、时间/空间复杂度、容易出错的用例。

### 第 2 周：框架与工程化

- React 路线：Hooks、渲染、状态分类、并发特性和 Next.js。
- Vue 路线：响应式、diff、生命周期、Router 和 Pinia。
- 工程化：构建、模块、Tree Shaking、包管理、类型/lint/test 门禁。
- 设计模式：每天复习 2 ～ 3 个，重点判断何时不该使用。

### 第 3 周：性能、服务端与数据

- 使用 Core Web Vitals 和真实用户数据建立性能诊断流程。
- 掌握 Node.js 事件循环、NestJS 请求边界和任务队列的幂等/重试。
- 掌握 MySQL 索引、事务、软删除唯一性和 Redis 缓存一致性。
- 学习 HTTP 接口的错误、幂等、权限和兼容演进。

### 第 4 周：场景与系统案例

- 对白屏、偶发 Bug、慢接口和发版事故做口头演练。
- 用项目复盘模板组织一个真实案例，不编造指标。
- 练习画数据流、状态机和故障恢复路径。
- 回看所有答错题，重新独立实现算法和代码示例。

## 一周路线

1. 第 1 天：JavaScript 异步、原型、this 与 Promise 手写。
2. 第 2 天：React/Vue 主框架和状态管理。
3. 第 3 天：浏览器网络、安全和缓存。
4. 第 4 天：工程化、性能和监控。
5. 第 5 天：Node、数据库、接口和队列。
6. 第 6 天：算法高频题 + 设计模式。
7. 第 7 天：场景排障、项目复盘和错题回看。

一周内不要追求阅读完所有文章。每个主题至少能回答：是什么、为什么、边界、如何验证。

## 一天路线

按顺序快速检查：

1. [JavaScript 目录](../01-JavaScript/目录.md)中的 Promise、事件循环、this、原型和闭包。
2. [算法高频题型](../01-JavaScript/手写题/算法-高频题型.md)中的复杂度、链表、树、二分和排序模板。
3. 主框架目录中的 Hooks/响应式、渲染和状态管理。
4. [场景题](../12-场景题/目录.md)的统一排障框架。
5. [项目复盘方法](../98-项目深挖/项目复盘方法.md)的一页摘要。

## 练习闭环

```text
阅读 → 合上文档复述 → 独立写代码/画图 → 用反例追问 → 记录错因 → 间隔复习
```

- 代码题必须运行边界用例，不只默写。
- 架构题必须说明约束和失败路径，不只画正常流程。
- 版本相关问题先说明版本，再给结论。
- 面试或实际工作中遇到的新问题，补到对应主题并附验证来源。
