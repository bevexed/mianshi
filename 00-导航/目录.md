## 推荐学习路径

```text
JavaScript / TypeScript / 浏览器
  → React 或 Vue / 工程化
  → 性能 / 场景排障 / Web 安全
  → Node / 数据库 / HTTP 接口
  → 架构 / AI / 系统案例
```

算法与代码设计适合贯穿练习：先写出正确版本和复杂度，再讨论抽象、边界与工程取舍。
