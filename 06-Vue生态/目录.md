## 🚧 这个模块的缺口

**9 篇里有 6 篇不足 25 行**，是全库最薄的模块之一。
如果面试官挑 Vue 深挖，现在的储备扛不住。

**必须补的**：
- **Pinia**（简历写了 Vuex/Pinia，但一篇没有）
- **Composition API 的设计动机**（不是 API 用法，是为什么比 mixin 好）
- **Vue3 的编译期优化**（静态提升、PatchFlag、Block Tree）——
  这是 Vue3 性能提升的真正来源，比 Proxy 更值得讲
- **`<script setup>`** 的语法糖展开

## 你的差异化素材

**别只讲 API 差异，讲你实际踩的**：

> 燊芒的 PMS 是 qiankun + Vue2/Vue3 子应用共存，
> 因为老项目迁不动、新功能想用 Vue3。
> 最麻烦的是 element-ui 和 element-plus **类名前缀都是 `el-`**，
> 样式冲突非常严重。
