# `<title>`、`<h1>`、`<b>`、`<strong>`、`<i>`、`<em>`

## `<title>` 与 `<h1>`

- `<title>` 位于 `<head>`，用于浏览器标签、书签标题和搜索结果标题候选。
- `<h1>` 是页面可见内容中的一级标题，参与文档标题层级。

它们服务不同场景，不应笼统比较谁“更重要”。两者可以相近，但 `<title>` 常加入站点名，
`<h1>` 更贴合当前页面内容；每页都应有清晰、唯一且与内容一致的标题。

## `<b>` 与 `<strong>`

- `<strong>` 表示重要性、严重性或紧迫性，默认通常加粗。
- `<b>` 表示需要吸引注意但不增加重要性，例如摘要中的关键词、产品名。

## `<i>` 与 `<em>`

- `<em>` 表示语气上的强调，嵌套可增加强调程度，默认通常斜体。
- `<i>` 表示与正文不同的语态或类别，例如术语、外文短语、思想活动。

视觉样式应交给 CSS。图标优先使用 SVG 和可访问名称，不要因为 `<i>` 默认斜体
就把它当成“专门的图标标签”。
