# CSS 层叠与特异性

不能只用“1000、100、10、1 相加”理解权重；特异性按三元组逐列比较：

1. ID 列
2. 类、属性、伪类列
3. 类型选择器、伪元素列

```css
#app .item      /* (1, 1, 0) */
.page .item     /* (0, 2, 0) */
ul > li::marker /* (0, 0, 3) */
```

高位列优先，不能用很多类“进位”成一个 ID。通配符和组合符不增加特异性。

## 现代伪类的规则

- `:where(...)` 的特异性始终为 `(0, 0, 0)`。
- `:is(...)`、`:not(...)`、`:has(...)` 取参数列表中最高的特异性。
- 内联 style 可看作独立的更高层级，不应简单塞进三元组。

## 特异性不是层叠的全部

浏览器先比较来源、重要性和层叠层，再比较特异性，最后才看源码顺序。
因此 `!important` 不是普通“最高权重”，不同来源和 `@layer` 仍有自己的层叠规则。

工程上优先使用低特异性的类和 `@layer` 管理覆盖关系，避免依赖 ID 和不断叠加
`!important`。继承值只有在元素没有匹配声明时才参与，不和直接匹配的声明比特异性。
