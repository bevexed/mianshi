# 行内、块级与空元素

## 默认表现不等于永久分类

HTML 元素有默认 UA 样式，但 CSS `display` 可以改变生成的盒子类型：

- 常见默认行内：`span`、`a`、`strong`、`em`。
- `img`、`input` 等是替换元素，虽然默认参与行内布局，但宽高规则和普通文本不同。
- 常见默认块级：`div`、`p`、`section`、`h1`～`h6`。

```css
display: inline; /* 不独占一行；普通非替换元素的 width/height 通常不生效 */
display: inline-block; /* 不独占一行，但可以设置宽高 */
display: block; /* 生成块盒，默认占满可用行宽 */
```

不要把“语义”与“视觉盒子”混为一谈：把 `<span>` 设为 block 不会让它获得 `<section>`
的语义，把 `<div>` 设为 inline 也不会改变 HTML 内容模型。

## 空元素（void elements）

空元素不能包含子节点，常见有：`img`、`input`、`br`、`hr`、`meta`、`link`、
`source`、`area`、`base`、`col`、`embed`、`track`、`wbr`。
HTML 中不需要写闭合标签；`<br />` 的斜杠只是兼容写法，不代表 XML 自闭合语义。
