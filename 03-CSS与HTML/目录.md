## 🚧 这个模块缺什么

以你的层级，真正可能被问的其实是下面这些，**目前一篇都没有**：

- **CSS 变量（自定义属性）** —— 主题切换、设计 token 的落地方式
- **Grid 布局** —— 现在比 flex 更常被问复杂布局
- **CSS-in-JS vs Tailwind vs CSS Modules** 的取舍
  （你简历里 Tailwind 用得很多，**这题大概率会问**）
- **容器查询（container query）** —— 组件级响应式
- **CSS 层叠层（`@layer`）** —— 解决样式优先级战争
- **暗色模式实现方案**

**建议**：这个模块投入不必大，但**Tailwind 的取舍那题要准备**，
因为它写在你简历上且属于"你选了它就要说明为什么"。
