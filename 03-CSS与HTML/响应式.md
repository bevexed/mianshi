# 响应式布局

响应式设计是在同一套内容和 URL 下，根据可用空间、用户偏好和设备能力调整布局，
不只是“手机和电脑共用 URL”。

## 基础 viewport

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
```

不要默认禁用缩放；`user-scalable=no` 会影响低视力用户。

## 常用手段

- 流式布局：百分比、`minmax()`、`clamp()`、`rem`、`vw`。
- Flex/Grid：内容驱动换行，减少针对具体机型的断点。
- 媒体查询：根据 viewport、输入能力、色彩偏好、减少动画偏好等调整。
- 容器查询：组件根据自身容器宽度变化，而不是只看整个窗口。
- 响应式图片：`srcset` / `sizes` / `<picture>`。

```css
.cards {
	display: grid;
	grid-template-columns: repeat(auto-fit, minmax(min(18rem, 100%), 1fr));
	gap: 1rem;
}

@media (width <= 48rem) {
	.sidebar {
		display: none;
	}
}

.panel {
	container-type: inline-size;
}
@container (width >= 30rem) {
	.card {
		grid-template-columns: 8rem 1fr;
	}
}
```

断点应由内容开始拥挤的位置决定，不要只按某几个设备型号硬编码。
