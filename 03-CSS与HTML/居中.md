# 水平与垂直居中

## 首选：Flex / Grid

```css
.parent {
	display: grid;
	place-items: center;
}

/* 或 */
.parent {
	display: flex;
	justify-content: center;
	align-items: center;
}
```

## 不知道子元素尺寸：定位 + transform

```css
.parent {
	position: relative;
}
.child {
	position: absolute;
	left: 50%;
	top: 50%;
	transform: translate(-50%, -50%);
}
```

## 只居中单行文字

水平用 `text-align: center`。固定高度下可让 `line-height` 等于高度实现视觉垂直居中，
但只适合单行文本；多行、字体缩放或换行时应使用 Flex/Grid。
