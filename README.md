## 内容约定

- 涉及框架、协议或浏览器版本的文章会说明版本边界；升级时以对应官方文档为准。
- 代码示例优先展示核心语义，省略生产细节时会明确标注。
- 性能和架构建议必须结合真实负载验证，不把经验口诀当作普遍定律。
- 安全、法律和数据一致性内容只提供通用知识；实际决策需要结合最新规则和具体上下文。
- 已过时或不适合通用主线的内容移入 [99-归档](99-归档/目录.md)，保留历史而不混入当前导航。

## 维护检查

新增或修改内容时至少检查：

1. 本地 Markdown 链接和图片存在；
2. 代码围栏成对、示例语法正确；
3. 术语和版本边界与同章一致；
4. 不包含地区、公司、个人履历、凭证和客户信息；
5. 旧方案标明历史背景或移入归档。
