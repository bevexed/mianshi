> 面向 **8 年前端 / 前端负责人** 的面试准备。
> 不是知识大全，是**为一次具体求职服务的作战手册**。

## 👉 从这里开始

- **[00-导航/目录.md](00-导航/目录.md)** —— 全库总览、各模块占比、精力怎么分配
- **[00-导航/复习路线.md](00-导航/复习路线.md)** —— 按剩余时间选路线

## 这个题库和一般八股文的区别

**一般题库按知识点组织，这个按「面试官会怎么问」组织。**

- **50% 的篇幅在 [13-项目深挖/](13-项目深挖/)** ——
  因为 8 年经验的面试，大部分时间是照着简历深挖，不是背八股
- **每个答案都标注了"为什么这么答"** ——
  哪句是加分句、哪句是防守句、哪句说了会减分
- **`【需确认】` 标记** ——
  凡是取决于你真实实现的地方都留空，**不替你编**。
  面试时编数字，一追细节就崩
- **诚实答法** ——
  没做过的、做得不够的，都给了怎么坦率说明的版本。
  承认边界比假装完美可信得多

## 使用约定

| 标记 | 含义 |
|---|---|
| ✅ | 内容完整 |
| ⚠️ | 内容偏薄或需更新 |
| 🚧 | 待补 |
| 📦 | 已归档 |
| 📎 | 图片/代码等附件 |
| ★★★ | 最高优先级 |
| 【需确认】 | **必须你自己填**，取决于真实实现 |

## 写在后面的话（2022 年的原话，仍然成立）

1. 有些东西就是要死记硬背，没办法
2. 大概知道，或者不能默背，就是不会
3. 会背不一定会用，同理会用不一定会背
4. 融会贯通是需要大量实践的
5. 前端知识广度太广，不可临时抱佛脚，需要平时多积累

**但要补一条**：

6. **到了这个年限，面试官不再考你背了多少，
   而是考你做过的决策站不站得住。**
   八股只要不出错，真正拉开差距的是项目讲得透、决策讲得清。
