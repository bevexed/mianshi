# DOM 事件流

## 三个阶段

1. **捕获阶段**：从 Window/Document 沿祖先向目标传播。
2. **目标阶段**：到达 `event.target`。
3. **冒泡阶段**：对可冒泡事件，从目标沿祖先返回。

```js
parent.addEventListener('click', onCapture, { capture: true });
parent.addEventListener('click', onBubble);
```

`event.target` 是最初触发事件的节点；`event.currentTarget` 是当前正在执行监听器的节点。
不是所有事件都冒泡，例如原生 `focus` / `blur` 不冒泡，可改用 `focusin` / `focusout`。

## 停止传播与阻止默认行为

- `event.stopPropagation()`：停止继续传播，不阻止当前节点的其他监听器。
- `event.stopImmediatePropagation()`：还会阻止当前节点后续监听器。
- `event.preventDefault()`：阻止可取消事件的默认行为，不等于停止传播。

监听器声明为 passive 时不能调用 `preventDefault()`；滚动相关事件使用 passive
有助于浏览器及时滚动，但确实需要阻止默认行为时要明确设置 `{ passive: false }`。
