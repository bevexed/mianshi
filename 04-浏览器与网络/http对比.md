# HTTP 方法、状态码与语义

> HTTP/1.1、HTTP/2、HTTP/3 的传输差异见 [HTTP 版本演进.md](HTTP版本演进.md)。

## 常见方法

| 方法    | 典型语义                                 | 安全 | 幂等   |
| ------- | ---------------------------------------- | ---- | ------ |
| GET     | 获取资源                                 | 是   | 是     |
| HEAD    | 只取与 GET 类似的响应头，不返回响应 body | 是   | 是     |
| POST    | 创建子资源、触发处理                     | 否   | 通常否 |
| PUT     | 用给定表示创建/整体替换目标资源          | 否   | 是     |
| PATCH   | 部分修改                                 | 否   | 不保证 |
| DELETE  | 删除目标资源                             | 否   | 是     |
| OPTIONS | 查询通信选项，CORS 预检会使用            | 是   | 是     |

“安全”表示按语义不应改变服务端状态；“幂等”表示同一请求执行多次的预期效果
与一次相同，不代表响应码、日志或时间戳完全相同。支付等非幂等业务通常使用幂等键防重。

## 常见状态码

- `200 OK`：请求成功。
- `201 Created`：创建成功，常配合 `Location`。
- `204 No Content`：成功但没有响应 body。
- `301` / `308`：永久重定向；308 保留方法和 body。
- `302` / `303` / `307`：临时或“查看其他资源”；307 保留方法和 body，
  303 通常改为 GET。
- `304 Not Modified`：条件请求验证未变化，复用缓存；不是普通 3xx 页面跳转。
- `400 Bad Request`：请求语法或参数无法处理。
- `401 Unauthorized`：实际语义是缺少或无效认证，通常带 `WWW-Authenticate`。
- `403 Forbidden`：身份可能已知，但没有权限。
- `404 Not Found`、`409 Conflict`、`422 Unprocessable Content`、`429 Too Many Requests`。
- `500`、`502`、`503`、`504`：源服务错误、网关错误、暂不可用、网关超时。

状态码只表达 HTTP 层结果。接口还需要稳定的业务错误码、可追踪 request id 和安全的错误信息。

## 请求和响应结构

HTTP 消息包含起始行、头字段和可选 body。头字段名大小写不敏感；HTTP/2/3 在线路上
使用二进制帧和小写伪头字段，但应用层仍通过方法、状态和头部语义交互。

不要把“HTTP 无状态”理解成服务端不能有 Session；它表示每个 HTTP 请求本身应携带
完成处理所需的上下文，跨请求会话由 Cookie、Authorization 或服务端存储等额外机制建立。
