# 事件委托（事件代理）

事件委托利用冒泡，在稳定的祖先节点上统一处理后代事件。它的主要价值不仅是减少监听器，
还包括自动覆盖之后动态插入的子节点。

```js
list.addEventListener('click', (event) => {
	const item = event.target.closest('[data-id]');
	if (!item || !list.contains(item)) return;
	selectItem(item.dataset.id);
});
```

关键边界：

- `event.target` 可能是按钮内的图标或文字节点对应元素，用 `closest()` 找业务节点。
- 必须确认找到的节点仍在委托容器内，避免 `closest()` 匹配到嵌套结构外部。
- 子节点调用 `stopPropagation()` 后，祖先委托监听器收不到事件。
- 不冒泡的事件不能直接委托；例如用 `focusin` 代替 `focus`。
- 委托不是越高越好；挂在 `document` 会扩大匹配范围和调试成本，应选择最近的稳定祖先。
