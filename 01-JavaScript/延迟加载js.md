# `script` 的 `async`、`defer` 与模块

| 写法            | 下载             | 执行时机                             | 顺序             | DOMContentLoaded |
| --------------- | ---------------- | ------------------------------------ | ---------------- | ---------------- |
| 普通 `<script>` | 遇到标签后下载   | 下载完立即执行，阻塞 HTML 解析       | 文档顺序         | 执行完后才触发   |
| `async`         | 与 HTML 解析并行 | 下载完立即执行，可能打断解析         | **不保证**       | 不等待全部 async |
| `defer`         | 与 HTML 解析并行 | HTML 解析完成后、DOMContentLoaded 前 | **保持文档顺序** | 会等待           |
| `type="module"` | 与 HTML 解析并行 | 默认类似 defer                       | 依赖图顺序       | 会等待           |

`async` 适合互不依赖的统计脚本；依赖 DOM 或有执行顺序要求的脚本用 `defer`。
动态 `import()` 用于按需加载模块，不等同于 script 标签的 `async`。
