# 深拷贝与浅拷贝

## 浅拷贝

浅拷贝只创建第一层容器，嵌套对象仍共享引用：

```js
const source = { nested: { value: 1 } };
const copy = { ...source };
copy.nested.value = 2;
console.log(source.nested.value); // 2
```

对象展开、`Object.assign()`、数组展开、`slice()` 都是浅拷贝。

## 优先考虑 `structuredClone`

现代浏览器和 Node.js 提供 `structuredClone(value)`，支持循环引用、
`Date`、`RegExp`、`Map`、`Set`、ArrayBuffer 等结构化可克隆类型。

它不能克隆函数、DOM 节点、`WeakMap` 等，也不会保留自定义 class 的原型、
属性描述符和 getter/setter 语义。需要转移大 ArrayBuffer 时可使用 `transfer` 选项。

## 为什么 JSON 方案不通用

```js
const copy = JSON.parse(JSON.stringify(value));
```

这个写法只适合明确可 JSON 序列化的数据：

- 循环引用会抛错。
- `BigInt` 会抛错。
- `undefined`、函数、symbol 属性值会丢失或在数组中变成 `null`。
- `Date` 变字符串，`Map` / `Set` 变普通空对象，`NaN` / `Infinity` 变 `null`。
- 自定义原型、不可枚举属性和 symbol 键不会保留。

## 支持循环引用和常见内置对象的手写版

```js
function deepClone(value, seen = new WeakMap()) {
	if (value === null || typeof value !== 'object') return value;
	if (seen.has(value)) return seen.get(value);

	if (value instanceof Date) return new Date(value.getTime());
	if (value instanceof RegExp) {
		const copy = new RegExp(value.source, value.flags);
		copy.lastIndex = value.lastIndex;
		return copy;
	}

	if (value instanceof Map) {
		const copy = new Map();
		seen.set(value, copy); // 必须先登记，否则自引用 Map 会无限递归
		for (const [key, item] of value) {
			copy.set(deepClone(key, seen), deepClone(item, seen));
		}
		return copy;
	}

	if (value instanceof Set) {
		const copy = new Set();
		seen.set(value, copy);
		for (const item of value) copy.add(deepClone(item, seen));
		return copy;
	}

	const copy = Array.isArray(value) ? [] : Object.create(Object.getPrototypeOf(value));
	seen.set(value, copy); // 在递归属性之前登记，才能处理循环引用

	for (const key of Reflect.ownKeys(value)) {
		const descriptor = Object.getOwnPropertyDescriptor(value, key);
		if ('value' in descriptor) descriptor.value = deepClone(descriptor.value, seen);
		Object.defineProperty(copy, key, descriptor);
	}
	return copy;
}
```

这个版本保留普通对象的原型和属性描述符，但仍不尝试复制函数、DOM、
`WeakMap`、`WeakSet`、TypedArray 等所有宿主或内置类型。生产代码应先明确
输入数据的类型边界，再选择 `structuredClone`、领域专用转换或成熟库，
不要声称一个几十行的函数能克隆“任意 JavaScript 值”。
