# 防抖与节流

## 区别

- **防抖（debounce）**：连续触发时重新计时，停止触发一段时间后只执行一次。
  适合搜索联想、表单校验、窗口 resize 后计算。
- **节流（throttle）**：连续触发时，最多每隔一段时间执行一次。
  适合滚动、拖拽和高频指标采样。

## 防抖

```js
function debounce(fn, wait) {
	let timer = null;

	function debounced(...args) {
		clearTimeout(timer);
		timer = setTimeout(() => {
			timer = null;
			fn.apply(this, args);
		}, wait);
	}

	debounced.cancel = () => {
		clearTimeout(timer);
		timer = null;
	};

	return debounced;
}
```

## 节流（首尾都执行）

```js
function throttle(fn, wait) {
	let lastTime = 0;
	let timer = null;

	function throttled(...args) {
		const remaining = wait - (Date.now() - lastTime);

		if (remaining <= 0) {
			clearTimeout(timer);
			timer = null;
			lastTime = Date.now();
			fn.apply(this, args);
		} else if (!timer) {
			timer = setTimeout(() => {
				timer = null;
				lastTime = Date.now();
				fn.apply(this, args);
			}, remaining);
		}
	}

	throttled.cancel = () => {
		clearTimeout(timer);
		timer = null;
		lastTime = 0;
	};

	return throttled;
}
```

面试时先确认是否需要首调用、尾调用、返回值和取消能力；不同需求对应不同实现。
