# `==`、`===` 与 `Object.is`

- `===` 不做隐式类型转换；类型不同直接为 false。
- `==` 按抽象相等比较规则转换类型，可能经过 ToPrimitive、字符串转数字等步骤，
  不是简单地“只比较值”或“只调用 valueOf”。
- `Object.is` 和 `===` 大体相同，但 `Object.is(NaN, NaN)` 为 true，
  `Object.is(+0, -0)` 为 false。

```js
0 == false; // true
'' == 0; // true
null == undefined; // true（特殊规则）
null == 0; // false
NaN === NaN; // false
Object.is(NaN, NaN); // true
```

业务代码默认使用 `===`。少数明确场景可以有意识地用 `value == null`
同时匹配 `null` 和 `undefined`，并用注释说明意图。
