# ES2020+ 新语法

> ES6 的部分见 [ES6.md](ES6.md)，这里只收 ES2020 之后的。

## 常用新增

| 特性                 | 版本   | 说明                           |
| -------------------- | ------ | ------------------------------ |
| `?.` 可选链          | ES2020 | `a?.b?.c`，短路返回 undefined  |
| `??` 空值合并        | ES2020 | 只在 null/undefined 时取右边   |
| `??=` `\|\|=` `&&=`  | ES2021 | 逻辑赋值                       |
| `Promise.allSettled` | ES2020 | 全部结束（不管成败）才 resolve |
| `Promise.any`        | ES2021 | **第一个成功**的就 resolve     |
| `String.replaceAll`  | ES2021 | 不用写正则 `/g` 了             |
| `Array.at(-1)`       | ES2022 | 支持负索引                     |
| `Object.hasOwn`      | ES2022 | 替代 `hasOwnProperty.call`     |
| **顶层 await**       | ES2022 | 模块顶层可直接 await           |
| **类私有字段 `#x`**  | ES2022 | 真正的私有，外部无法访问       |
| `Array.findLast`     | ES2023 | 从后往前找                     |
| `Object.groupBy`     | ES2024 | 按 key 分组                    |

---

## `??` 和 `||` 的区别（高频）

- `||` 在**假值**（`0`、`''`、`false`、`null`、`undefined`、`NaN`）时走右边
- `??` **只在 `null` / `undefined`** 时走右边

**典型 bug**：

```js
const pageSize = input || 10; // ❌ 用户输入 0 会变成 10
const pageSize = input ?? 10; // ✅
```

---

## 可选链的注意点

- `a?.b` 只在 `a` 是 `null`/`undefined` 时短路，
  **其他假值（`0`、`''`）会继续访问**
- 支持三种形式：`a?.b`、`a?.[key]`、`a?.()`
- **短路是整条链**：`a?.b.c.d` 中 a 为 null 时，后面整体不执行，不会报错

## 类私有字段 `#x`

```js
class Counter {
	#count = 0; // 真私有，外部无法访问
	static #instances = 0; // 静态私有
	#increment() {
		this.#count++;
	} // 私有方法

	get value() {
		return this.#count;
	}
	static has(obj) {
		return #count in obj;
	} // ES2022 的 in 检测
}
```

和 `Symbol` 模拟私有、`_` 命名约定的区别：
`#` 是**语言层面强制**的，外部访问直接语法报错，
而前两者只是"约定俗成"或"不易发现"。
