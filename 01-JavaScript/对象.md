# 对象

## 基本认识

- 对象可以通过对象字面量、`Object.create()`、构造函数或 class 创建，
  并不是都由显式 `new` 创建。
- 属性键只能是 **string 或 symbol**；数字等其他值会先转换成 string。
- 对象赋值和比较处理的是引用：两个结构相同但独立创建的对象并不相等。
- 属性查找先看自身属性，再沿 `[[Prototype]]` 链向上查找，
  不会去“构造函数函数体”里搜索。

```js
const first = { value: 1 };
const second = first;
second.value = 2;

console.log(first.value); // 2
console.log({ a: 1 } === { a: 1 }); // false
```

原型链详见 [原型链.md](原型链.md)，键顺序和 `Map` 的区别见
[Map 与 WeakMap.md](Map与WeakMap.md)。
