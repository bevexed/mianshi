# 原型链

1. 原型链就是把原型串联起来
2. 原型链的最顶端是 null

## 原型可以解决的问题

对象可以共享属性和方法

## 谁有原型

1. **函数**拥有 `prototype`（指向它作为构造函数时，实例的原型）
2. **所有对象**都有 `__proto__`（指向自己的原型）

> ⚠️ **补充**：**函数本身也是对象**，
> 所以可作为构造函数的普通函数**既有 `prototype` 也有 `__proto__`**。
> 原文说"函数有 prototype、对象有 `__proto__`"容易被理解成二选一。

```js
function Foo() {}
Foo.prototype; // Foo 的实例的原型
Foo.__proto__; // === Function.prototype（Foo 自己的原型）
```

## 对象如何查找属性 / 方法

> ⚠️ **原文的查找顺序是错的**：
> 原文写「对象本身 → **构造函数中找** → 对象原型 → **构造函数原型** → ...」
>
> **属性查找不会去构造函数里找。**
> 构造函数自己的属性（静态属性）**不在实例的原型链上**。

**正确的查找链**：

```
obj 自身属性
  ↓ 找不到，沿 __proto__ 向上
obj.__proto__            （=== 构造函数.prototype）
  ↓
obj.__proto__.__proto__
  ↓ ...
Object.prototype
  ↓
null                     ← 到顶，返回 undefined
```

```js
function Person(name) {
	this.name = name;
} // 实例属性
Person.prototype.say = function () {}; // 原型方法 ← 实例能访问
Person.staticFn = function () {}; // 静态属性 ← 实例访问不到！

const p = new Person('a');
p.name; // 'a'      自身属性
p.say; // function 从 Person.prototype 找到
p.staticFn; // undefined ← 证明不会去构造函数里找
```

**这个例子可以直接用来回答面试**，比背顺序有说服力。

## 相关的几个高频点

### `new` 做了什么

```js
function myNew(Fn, ...args) {
	const obj = Object.create(Fn.prototype); // 1. 创建对象，原型指向 Fn.prototype
	const res = Fn.apply(obj, args); // 2. 执行构造函数，this 指向新对象
	const isObject = res !== null && (typeof res === 'object' || typeof res === 'function');
	return isObject ? res : obj; // 3. 构造函数返回对象/函数就用它
}
```

见 [手写题/new 操作符.md](手写题/new操作符.md)

### `instanceof` 原理

```js
function myInstanceof(obj, Fn) {
	if ((typeof obj !== 'object' && typeof obj !== 'function') || obj === null) return false;
	let proto = Object.getPrototypeOf(obj);
	while (proto) {
		if (proto === Fn.prototype) return true;
		proto = Object.getPrototypeOf(proto);
	}
	return false;
}
```

**对普通构造函数而言，本质是沿原型链找 `Fn.prototype`。**
原生 `instanceof` 还会遵循构造函数自定义的 `Symbol.hasInstance`，并校验右值是否可调用；
上面只是面试用的核心路径。

### 三个关系式（能背下来很稳）

```js
function Foo() {}
const f = new Foo();

f.__proto__ === Foo.prototype;
Foo.prototype.__proto__ === Object.prototype;
Object.prototype.__proto__ === null; // 原型链的顶端

Foo.__proto__ === Function.prototype; // 函数也是对象
Function.prototype.__proto__ === Object.prototype;
```

### `__proto__` 和 `Object.getPrototypeOf`

`__proto__` 是历史访问器，已为 Web 兼容被纳入规范附录；新代码推荐用：

```js
Object.getPrototypeOf(obj);
Object.setPrototypeOf(obj, proto); // ⚠️ 会导致引擎优化失效，性能差，慎用
```
