# 函数

## 函数是一等值

JavaScript 函数可以赋值给变量、作为参数传入、作为返回值返回，
也可以像普通对象一样拥有属性。`typeof fn === 'function'`，但函数本质上仍是可调用对象。

## `arguments` 和剩余参数

普通函数里有一个类数组 `arguments`，包含本次调用传入的实参：

```js
function oldStyle() {
	return Array.from(arguments);
}
```

现代代码优先使用剩余参数，它是真数组，名字也更清楚：

```js
function sum(...numbers) {
	return numbers.reduce((total, number) => total + number, 0);
}
```

- 箭头函数没有自己的 `arguments`，访问时会沿词法作用域向外查找。
- `arguments` 不是“参数个数未知时才使用”；剩余参数通常是更合适的 API。
- 非严格模式下，简单参数与 `arguments` 可能存在历史性的双向映射，严格模式没有，
  因此不要依赖这个行为。

## 柯里化

柯里化把接收多个参数的函数转换为一连串接收部分参数的函数：

```js
const add = (x) => (y) => x + y;
add(1)(2); // 3
```
