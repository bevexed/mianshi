## 引用类型

1. object

> `NaN` 是 number 类型的一个特殊值（不是独立类型）。
> 它是**唯一不等于自身的值**：`NaN !== NaN`，
> 判断要用 `Number.isNaN()`（`isNaN()` 会先做类型转换，不可靠）。

## 考题

```js
console.log(typeof NaN); // 'number'
console.log(typeof undefined); // 'undefined'
console.log(typeof null); // 'object'  ← 历史遗留 bug
console.log(typeof function () {}); // 'function' ← 函数是可调用对象，typeof 特殊返回 function
console.log(typeof Symbol()); // 'symbol'
console.log(typeof 1n); // 'bigint'
```

> ⚠️ **原文这行的答案是错的**：
>
> ```js
> console.log(typeof undefined + 1); // 原文写 NaN ❌
> ```
>
> **正确答案是 `'undefined1'`**。
>
> **为什么**：`typeof` 的优先级高于 `+`，
> 所以先算 `typeof undefined` 得到**字符串** `'undefined'`，
> 再和 `1` 做**字符串拼接** → `'undefined1'`。
>
> 要得到 NaN 得加括号：
>
> ```js
> typeof (undefined + 1); // undefined + 1 = NaN，typeof NaN = 'number'
> ```
>
> **这题的考点正是运算符优先级**，答成 NaN 就掉进坑里了。

## typeof 的四个坑

| 表达式                | 结果          | 说明                                              |
| --------------------- | ------------- | ------------------------------------------------- |
| `typeof null`         | `'object'`    | 历史 bug，无法修复（会破坏太多代码）              |
| `typeof function(){}` | `'function'`  | 函数是对象，但 typeof 特殊对待                    |
| `typeof []`           | `'object'`    | 判断数组要用 `Array.isArray()`                    |
| `typeof 未声明变量`   | `'undefined'` | 通常不报错；但同一作用域 TDZ 中的词法绑定仍会抛错 |

## 类型判断的四种方式

```js
typeof x; // 只能区分原始类型 + function
x instanceof Array; // 靠原型链，跨 iframe 会失效
Array.isArray(x); // 判断数组的标准方式
Object.prototype.toString.call(x); // '[object Array]' 最通用
```

`Object.prototype.toString.call()` 能区分许多内置类型：

```js
Object.prototype.toString.call(null); // '[object Null]'
Object.prototype.toString.call([]); // '[object Array]'
Object.prototype.toString.call(new Date()); // '[object Date]'
```

它也不是不可伪造的运行时校验：对象可以通过 `Symbol.toStringTag` 改变结果。
类型判断应根据具体目标选择 `Array.isArray`、`typeof`、品牌检查或 schema 校验。

## null 和 undefined 区别

`null` 和 `undefined` 都是原始值：

- `undefined` 通常表示“尚未赋值”或“缺少返回值/属性”。
- `null` 通常由开发者显式表示“这里有值的位置，但当前为空”。
- `Number(null)` 是 `0`，`Number(undefined)` 是 `NaN`；这只是类型转换规则，
  不能据此把 `null` 称为对象。`typeof null === 'object'` 是历史遗留结果。
