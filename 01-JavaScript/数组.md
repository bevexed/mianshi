# 数组

## 判断数组

```js
Array.isArray(value); // 标准方式，跨 iframe 也可靠
```

`typeof []` 是 `'object'`；`instanceof Array` 会受不同 realm 的原型影响。

## 会不会修改原数组

| 修改原数组                                        | 返回新数组/值，不修改原数组                   |
| ------------------------------------------------- | --------------------------------------------- |
| `push`、`pop`、`shift`、`unshift`                 | `slice`、`concat`                             |
| `splice`、`sort`、`reverse`、`fill`、`copyWithin` | `map`、`filter`、`flat`、`flatMap`            |
|                                                   | `toSorted`、`toReversed`、`toSpliced`、`with` |

- `splice(start, deleteCount, ...items)` 修改原数组，返回被删除元素。
- `slice(start, end)` 返回 `[start, end)` 的浅拷贝；不传参数时返回完整浅拷贝。
- `map` 始终返回与原数组等长的新数组，不是“有 return 才返回”也不是过滤。
- `forEach` 返回 `undefined`，不能用 `break` / `continue` 提前结束；
  需要短路时用 `some`、`every`、`find` 或普通循环。

## 排序

`sort()` 默认把元素转成字符串后按 UTF-16 码元顺序比较：

```js
[2, 10]
	.sort() // [10, 2]
	[(2, 10)].sort((a, b) => a - b); // [2, 10]
```

`sort` 会修改原数组；需要不可变写法时用 `toSorted`，或兼容旧环境时先复制：

```js
const sorted = [...numbers].sort((a, b) => a - b);
```

### 冒泡排序

```js
function bubbleSort(input) {
	const result = [...input];
	for (let end = result.length - 1; end > 0; end--) {
		let swapped = false;
		for (let i = 0; i < end; i++) {
			if (result[i] > result[i + 1]) {
				[result[i], result[i + 1]] = [result[i + 1], result[i]];
				swapped = true;
			}
		}
		if (!swapped) break;
	}
	return result;
}
```

时间 O(n²)，已经有序时因提前退出为 O(n)，额外空间 O(n)（因为示例不修改输入）。

## 去重

原始值可直接使用 `Set`：

```js
const unique = [...new Set([1, 2, 2, 3])];
```

对象数组通常按业务主键去重：

```js
function uniqueBy(items, getKey) {
	const map = new Map();
	for (const item of items) {
		const key = getKey(item);
		if (!map.has(key)) map.set(key, item); // 保留第一次出现的项
	}
	return [...map.values()];
}

uniqueBy(users, (user) => user.id);
```

`JSON.stringify` 去重不可靠：键插入顺序可能不同，而且 `undefined`、函数、
symbol、`BigInt`、循环引用和特殊对象都有丢失或报错问题。

## 扁平化

const result = [1, [2, [3]]].flat(Infinity); // [1, 2, 3]
