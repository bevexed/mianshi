# 闭包

## 定义

函数创建时会记住它的词法环境；函数在原作用域之外执行时，
仍能访问当时环境中的变量，这种函数与词法环境的组合就是闭包。

```js
function createCounter() {
	let count = 0;
	return () => ++count;
}

const next = createCounter();
next(); // 1
next(); // 2
```

## 用途

- 封装私有状态
- 创建带配置的回调、函数工厂和柯里化函数
- 在异步回调中保留上下文

## 内存边界

闭包本身不是内存泄漏。只要闭包仍可达，它引用的词法环境就不能被回收；
如果长生命周期的定时器、事件监听器或缓存意外保留了闭包，才可能造成泄漏。
正确做法是清理不再需要的监听和定时器，而不是笼统地“用完闭包就清理”。
