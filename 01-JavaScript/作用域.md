# 作用域与提升

## 作用域类型

- `var` 是函数作用域；函数外声明时属于脚本或全局作用域。
- `let`、`const` 和 class 是块级作用域。
- 函数声明和变量解析遵循**词法作用域**：由代码写在哪里决定，不由调用位置决定。

## 提升与 TDZ

```js
console.log(value); // undefined
var value = 1;

console.log(name); // ReferenceError：声明前处于 TDZ
let name = 'a';
```

`var` 绑定在进入作用域时初始化为 `undefined`；函数声明会连同函数值一起初始化。
`let` / `const` 绑定也已经建立，但执行声明前不能访问，这段区间叫 TDZ。

## 一个常见的隐式全局陷阱

```js
function run() {
	var local = (leaked = 10);
}
run();
console.log(leaked); // 非严格脚本里可能是 10
console.log(local); // ReferenceError
```

它等价于先给未声明标识符 `leaked` 赋值，再声明局部 `local`。
严格模式或 ES Module 中，给未声明变量赋值会直接抛出 `ReferenceError`。

## 变量遮蔽

```js
function outer() {
	const value = 1;
	function inner() {
		console.log(value); // 读取 outer 的 value
		const own = 2;
		return own;
	}
	return inner();
}
```

当前作用域找不到标识符时才沿外层词法环境查找；不会因为调用者有同名变量而改变。
