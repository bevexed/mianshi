# 简历深挖

> 面试的主战场不是八股，是**照着简历逐条深挖**。这个目录就是把
> [简历带项目.md](../../jianli/简历带项目.md) 里的每一段经历，翻译成
> 「面试官会怎么问 + 我怎么答」。
>
> 八年经验的面试里，八股大概占 20-30%，剩下全在这里。

## 怎么用

1. **先看 `0. 一句话自述`**——每篇开头都有一段 60 秒的项目自述，
   目的是**主动埋钩子**，把面试官引到你准备好的区域，而不是被动等他挑
2. **`【需确认】` 标记必须清掉**——这些地方的答案取决于你的真实实现，
   我不能替你编。回去翻代码/部署脚本确认后填进去。**面试时编数字是自杀**
3. **能画的一定要画**——架构图、数据链路、状态机。白板上画出来的可信度
   远高于口述

## 一条贯穿全篇的主线

有三段经历指向同一个方法论，**串起来讲会显得你的认知是成体系的**：

- 工程汇后台的「**表单状态该由谁持有**」
- 微信 H5 的「**邀请人被固定**」bug（URL 参数 vs 缓存，优先级未定义）
- 微信 H5 把 `useUrlState` 换成 `useSearchParams`（**URL 作为唯一来源**）

→ 统一收敛为：**同一份数据只能有一个权威来源。**

再加上采集服务的「**先画状态机再写代码**」，
你就有了两条可以反复调用的个人方法论。
面试官记住的从来不是你会什么框架，是你有没有自己的判断方式。
