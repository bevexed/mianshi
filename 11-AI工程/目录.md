## 事实标签说明

- Codex、Claude Code 是实际使用的工具；其余工具仅作为行业认知。
- 标有 `【需本人确认】` 的内容不能在面试中按事实口述，应先按自己的经历核实或改写。

## 推荐顺序

1. [AI 辅助开发实践](AI辅助开发实践.md)：先建立工具协作闭环和质量边界。
2. [Codex 与 Claude Code 协作实践](Codex与Claude Code协作实践.md)：再用实际使用经验组织口述。
3. [AI 辅助开发真实案例](AI辅助开发真实案例.md)：用真实案例说明 AI 与人工如何分工和修正。
4. [AI 辅助开发面试题](AI辅助开发面试题.md)：按追问链练习短答与展开。
5. [AI 开发工具生态与选型](AI开发工具生态与选型.md)：补充行业认知和选型边界。

MCP、RAG 适合作为项目深入追问：分别说明外部能力连接，以及可更新、可评测的证据上下文。

## 关键原则

- 模型输出、检索资料和工具参数都需要验证。
- 权限控制必须由应用和服务端执行，不能交给 prompt。
- 先定义评测与完成标准，再优化模型、检索或工具描述。
- 涉及版本的协议和 SDK 行为，以对应版本的官方文档为准。
