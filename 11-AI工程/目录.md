## 推荐顺序

1. 先理解 Agent 的工具闭环与质量边界。
2. 再学习 MCP 如何标准化 Host 与外部能力的连接。
3. 最后学习 RAG 如何提供可更新、可评测的证据上下文。

## 关键原则

- 模型输出、检索资料和工具参数都需要验证。
- 权限控制必须由应用和服务端执行，不能交给 prompt。
- 先定义评测与完成标准，再优化模型、检索或工具描述。
- 涉及版本的协议和 SDK 行为，以对应版本的官方文档为准。
