# 什么是性能优化

在互联网网站百花齐放的今天，网站响应速度是用户体验的第一要素，其重要性不言而喻

## 性能的起因
1. <font style="color:rgb(51, 51, 51);background-color:rgb(253, 253, 253);">提高产品核心竞争力</font>
2. <font style="color:rgb(51, 51, 51);background-color:rgb(253, 253, 253);">提高用户体验</font>

<font style="color:rgb(51, 51, 51);background-color:rgb(253, 253, 253);"></font>

## <font style="color:rgb(51, 51, 51);background-color:rgb(253, 253, 253);">性能的影响</font>
1. 用户的留存
2. 网站的转换率
3. 传播和体验

## 性能的评估模型


![画板](https://cdn.nlark.com/yuque/0/2022/jpeg/1460101/1646030693847-f558e54e-c7a5-416e-9aad-6706841c3ab2.jpeg)



### 响应
1. 用户感知延迟之前接受到操作的反馈
    1. 文本输入
    2. 单机按钮
    3. 表单切换
    4. 启动动画操作等
2. 时间尽量控制在 100ms 之内

### 动画
1. 尽量保持在 60 帧

### 空闲
1. 在浏览器空闲的时候处理可以延迟的任务

### 加载
白屏时间应尽量小于1s

| <font style="color:#262626;">延迟</font> | <font style="color:#262626;">用户反应</font> |
| --- | --- |
| 0~16ms | 一人眼可以感知每秒 60帧的动画转场，即每帧 16ms， 除了浏览器将一帧画面绘制到屏幕上的时间，网站应用大约需要 10ms 来生成一帧 |
| 0~100ms | 在该时间窗口内响应用户操作，才会是流畅的体验 |
| 100~300ms | 用户能感知轻微的延迟 |
| 300~1000ms | 所感知的延迟会被用户当作网站页面加载或更改视图过程的一部分 |
| >1s | 用户的注意力将离开之前正在执行的任务 |
| >10s | 用户感到失望，可能会放弃任务 |




## 性能优化的步骤
### 性能测量
根据测量工具的建议进行优化

1. Chrome 的 Performance
2. Lighthouse

### 页面加载生命周期
通过分析页面加载生命周期的方式，逐一步骤优化性能

![画板](https://cdn.nlark.com/yuque/0/2022/jpeg/1460101/1646032395906-4957838e-a70a-4d45-9265-a0d39cf2488c.jpeg)



### 优化方案
1. 传输资源优化
    1. 图像资源
2. 加载过程优化
    1. 首屏加载优化
    2. 去除不必要的加载
3. js优化
    1. 压缩
    2. 书写规范
    3. 逻辑严谨
4. 关键渲染路径优化
    1. 避免重绘和回流
5. 本地存储和浏览器缓存
